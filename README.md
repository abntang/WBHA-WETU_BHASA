# **WBHA — Wetu Bhasa**

<p align="justify">
WBHA (Wetu Bhasa) is a digital gallery and web application dedicated to showcasing the historical heritage of Majapahit inscriptions. It blends clean modern editorial aesthetics with an immersive user experience, presenting ancient stone transcripts, translations, and historical artifacts in a structured and engaging format.
</p>

## **Design Philosophy**

<p align="justify">
The interface adopts a sophisticated and balanced design philosophy, prioritizing content clarity, thoughtful whitespace, and precise typographic hierarchy. Every component is crafted to evoke a refined museum atmosphere, ensuring a seamless and captivating browsing experience across both desktop and mobile screens.
</p>

## **Getting Started**

Clone this repository and install the required dependencies to run the project locally.

```bash
git clone [https://github.com/abntang/wbha-wetu-bhasa.git](https://github.com/abntang/wbha-wetu-bhasa.git)
cd wbha-wetu-bhasa
npm install
npm run dev
```
